# WidgetBridge documentation

WidgetBridge is an editor plugin for Unreal Engine 5.7 (Windows) for UMG widget blueprints. It creates a widget blueprint from
a C++ `UUserWidget` class (one widget per `BindWidget` property), keeps the two in sync, and lets an external program read and
edit widget trees through JSON files.
